# Video Transcriber Pro - Employee Quick Start Guide

## 🚀 Getting Started (First Time)

### 1. Install the Application
**Option A - Installer (Easy):**
- Double-click `VideoTranscriberPro-Installer.exe`
- Click Next → Next → Install
- ✓ Done! Icon appears on Desktop

**Option B - Standalone (Portable):**
- Copy `VideoTranscriberPro.exe` to any folder
- Double-click to run
- ✓ Ready to use!

---

## 🔑 Step 1: Enter Your API Key (First Time Only)

1. **Open** Video Transcriber Pro
2. **Screen shows:** "AssemblyAI API Key (First Time Setup)"
3. **Click** in the text box
4. **Paste** your API key (provided by IT)
5. **Click** "🚀 Start Transcription" to save it

✅ **Your API key is now saved!** You won't need to enter it again.

---

## 📹 Step 2: Select Your File

1. **Click** "📁 Browse Video" button
2. **Choose a file:**
   - Video: MP4, MKV, MOV, AVI, etc.
   - Audio: MP3, WAV, FLAC, M4A, etc.
3. **Click Open**
4. ✓ File selected! Shows filename and size

---

## 🎚️ Step 3: Choose Quality (Important!)

**Audio Compression Quality dropdown:**

| Option | Speed | Quality | Best For |
|--------|-------|---------|----------|
| **64 kbps** | Slow (⏳) | Excellent | Short videos, critical accuracy |
| **48 kbps** | Medium (⏱️) | Good | Balanced use |
| **32 kbps** | Fast (⚡) | Good | **RECOMMENDED** - Best overall |

**💡 Tip:** 32 kbps is recommended! You won't notice quality difference but it's much faster.

---

## ▶️ Step 4: Start Transcription

1. **Click** "🚀 Start Transcription"
2. **Watch** the progress bar
3. **Don't close** the app during processing
4. Status shows:
   - Compressing audio...
   - Uploading & Transcribing...
   - Done!

---

## ✅ Step 5: Get Your Results

After completion:
- **Transcript saved** automatically
- **Location:** `Downloads\[filename]\`
- **Files created:**
  - `transcript.txt` - Your transcript
  - `subtitles.srt` - Subtitle file
  - `*_audio.mp3` - Audio file used

## 🆘 Common Issues & Fixes

### ❌ "API Key Required" Error
- **Problem:** API key is missing or wrong
- **Fix:** Click "🔑 Change API Key" → Paste correct key

### ❌ "Invalid Format" Error
- **Problem:** File type not supported
- **Fix:** Use: MP4, WAV, FLAC, MP3, MKV, MOV, AVI, etc.

### ❌ Slow Transcription
- **Problem:** Large file or slow internet
- **Fix:** Use 32 kbps quality → Select WAV/FLAC → They compress automatically

### ❌ App Says "Cancelled"
- **Problem:** Internet disconnected or app closed
- **Fix:** 
  - Check internet connection
  - Don't close app during processing
  - Try again with smaller file

### ❌ App Won't Start
- **Problem:** Installation issue
- **Fix:** 
  - Uninstall completely
  - Restart computer
  - Reinstall from fresh installer

## 💾 Changing Your API Key Later

If you need to update your API key:
1. **Open** Video Transcriber Pro
2. **Click** "🔑 Change API Key"
3. **Paste** new API key
4. **Start any transcription** to save new key

---

## 🎯 Pro Tips

✅ **Use 32 kbps** - Best balance of quality and speed  
✅ **Internet first** - Check connection before starting  
✅ **Keep app open** - Don't close during transcription  
✅ **One file at a time** - Don't run multiple transcriptions  
✅ **WAV files?** - App compresses them automatically  
✅ **Large videos?** - Use 32 or 48 kbps, not 64 kbps
