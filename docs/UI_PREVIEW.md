## Application States

### 🟢 Ready State
- Waiting for user action
- File not selected
- Can change API key
- Can browse files
- "Start" button disabled

### 🟡 Processing State
- File selected
- Transcription running
- Progress bar visible
- Can cancel
- "Start" button disabled

### 🔴 Error State
- Invalid file format
- Missing API key
- Network error
- Processing cancelled

---

## Key User Interactions

### First Time User Flow
```
1. Open app
2. See "API Key (First Time Setup)"
3. Paste API key
4. Select file
5. Choose quality
6. Start transcription
7. ✅ Key saved for next time!
```

### Returning User Flow
```
1. Open app
2. See "✓ API Key Saved"
3. [Optional] Click "Change API Key"
4. Select file
5. Choose quality
6. Start transcription
7. ✅ Done! (No key entry needed)
```

## Visual Indicators

### Status Messages
| Message | Meaning |
|---------|---------|
| Ready. | Waiting for user |
| File selected! | Ready to transcribe |
| 🎬 Step 1/3: Extracting... | Compressing audio |
| 📤 Uploading & Transcribing | Sending to API |
| 🎉 Done! Files saved | Complete |
| ❌ Transcription cancelled | Stopped by user |

### UI Elements
- ✓ = Success/Complete
- ⚠️ = Warning
- ℹ️ = Information
- ❌ = Error/Cancel
- 🚀 = Start action
- ⛔ = Stop action
- 📁 = File browser
- 🔑 = Settings
